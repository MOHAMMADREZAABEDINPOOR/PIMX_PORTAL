## ⚡ Features
- 🧭 **Unified Ecosystem Navigation**: Quick access to PIMX_NET, PIMX_PASS, PIMX_PLANNER, PIMX_MOJI, and bots.
- 🌍 **Full Bilingual Experience**: Native English and Persian (RTL) mode with smooth dark glassmorphism.
- 📊 **Status & Health Badges**: Live operational indicator of active PIMX microservices.
